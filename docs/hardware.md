# Hardware

Known targets and target families in the focused LastSwarm set:

- M5Stack Core2
- M5Stick / Cardputer-style ESP32 devices
- M5 Atom / Atom Matrix / AtomS3-style devices
- ESP32-S3 Geek-style display node
- TMOS / PIR / STHS34PF80-style presence sensors
- ENV / pressure / temperature / microphone paths where supported by a sketch
- ESP-NOW peer-to-peer communication
- Wi-Fi for sketches that explicitly use network or Stratum paths

Hardware validation was not performed during repository cleanup.
