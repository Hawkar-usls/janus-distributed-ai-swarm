# Ramanujan Theta Policy

Some LastSwarm firmware, especially `firmware/zim_geek/Zim.ino`, uses Ramanujan/theta terminology for bounded local policy signals.

In this repository, theta-like logic is treated as a control signal for scheduling, confidence, UI state, exploration pressure, or telemetry interpretation. It does not replace measured sensor data, packet verification, Stratum events, or hardware validation.
