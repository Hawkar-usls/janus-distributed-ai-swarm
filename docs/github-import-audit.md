# GitHub Import Audit

The public main branch was narrowed to the current LastSwarm firmware set.

## Included

- Eight current LastSwarm `.ino` files.
- Minimal docs for architecture, hardware, ESP-NOW, calibration, technical boundaries, and M5Stack review.
- Minimal config examples with placeholders only.
- Static audit reports for the included firmware.

## Excluded

- Older firmware branches and broad preserve archives.
- Non-firmware side projects and runtime tooling.
- Raw logs, databases, model/checkpoint artifacts, archives, and bulk runtime samples.
- Unrelated research notes and scratch experiments.
- Secrets, private keys, Wi-Fi passwords, and tokens.
